CardManager.RefreshCardCoroutine 수정 전·후

이번 적용 범위: 카드 재배치의 시간 진행·보간 반복문 한 곳. 수정 전 파일은 이번 작업 직전의 작업 트리를 보존합니다.

수정 전수정 후
        float elapsed = 0f; 

        while (elapsed < animDuration)
        {
            elapsed += Time.unscaledDeltaTime;

            float t = Mathf.Sin(
                elapsed / animDuration * Mathf.PI * 0.5f
            );

            rect.anchoredPosition =
                Vector2.Lerp(startPos, targetPos, t);

            yield return null;
        }
        yield return UIAnimationRoutine.Run(
            animDuration,
            progress => Mathf.Sin(progress * Mathf.PI * 0.5f),
            t => rect.anchoredPosition = Vector2.Lerp(startPos, targetPos, t));
  • 유지: 첫 프레임 대기, 카드 간격·목표 위치 계산, unscaled 시간, Sin 곡선, 최종 위치 보정.
  • 차이: 공통 함수는 시작값을 적용한 뒤 대기합니다. 기존은 시간을 증가시켜 적용한 뒤 대기합니다.
  • 차이: 진행률을 0~1로 제한하고 최종값을 적용합니다. 기존 반복문의 초과 진행률과는 다릅니다.
  • 기존 동시 재배치 코루틴의 중복 실행·취소 정책은 변경하지 않았습니다. Unity 실행 검증은 별도 필요합니다.
